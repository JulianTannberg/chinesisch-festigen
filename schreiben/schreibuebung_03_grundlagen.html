Wähle dein System aus. Du musst diese Einstellung in der Regel nur einmal vornehmen.

iOS (iPhone/iPad)
Einstellungen → Allgemein → Tastatur → Tastaturen → Tastatur hinzufügen → Chinesisch (Pinyin)
In der Übung: 🌐 gedrückt halten → Chinesisch auswählen
Android
Einstellungen → System → Sprache & Eingabe → Tastatur → Chinesisch (Pinyin) aktivieren
In der Übung: Sprache über Weltkugel / Leertaste wechseln
Windows 10/11
Einstellungen → Zeit & Sprache → Sprache & Region → Sprache hinzufügen → Chinesisch
Umschalten: Win + Leertaste → Microsoft Pinyin
macOS
Systemeinstellungen → Tastatur → Eingabequellen → + → Chinesisch → Pinyin
Umschalten über Menüleiste oder Ctrl/⌘ + Leertaste
